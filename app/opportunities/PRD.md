# 딸각 PRD — ① 기회 정보 큐레이션 (구현 기준)

> 원본: `(최종본) 7조딸깍_PRD.docx` (작성일 2026-10-03). 이 문서는 그중 **① 기회 정보 큐레이션** 부분만 추려 구현 기준으로 정리한 것이다. 기능을 추가하거나 바꾸면 이 문서를 같이 고친다. 원본과 다르면 제출 전에 팀과 맞춘다.

## 1. 서비스 맥락

- 팀: 7조 · 딸각 / 서비스명: AI 기반 학업지원 정보중계 플랫폼 서비스
- 이 서비스: 대학생·대학원생이 여러 사이트에 흩어진 공모전·대외활동·장학금·해커톤 정보를 일일이 찾는 문제를 AI 통합 검색과 맞춤 추천으로 해결한다.
- 경로: `/opportunities` · 폴더: `app/opportunities/`

## 2. 문제와 사용자

- 정보가 여러 웹사이트와 기관 홈페이지에 흩어져 있다.
- 모집 분야, 지원 자격, 마감일을 직접 비교해야 하고, 공고 형식이 달라 자격 확인에 시간이 오래 걸린다.
- 관심 있는 공모전을 발견해도 마감일을 놓치거나 적합 여부를 판단하기 어렵다.
- 대상: 대학생·대학원생, 취업 준비생, 연구·개발 프로젝트 경험을 원하는 학생, 공모전·해커톤 참가자를 찾는 학생
- 사용 상황: 등·하교 중 스마트폰으로 새 공모전 확인, 포트폴리오 활동 탐색, 방학 계획, 전공 관련·마감 임박 공모전 확인

## 3. 차별점

- 단순 목록 제공이 아닌 AI 기반 개인화 추천과 적합성 설명
- 긴 모집공고를 핵심 내용으로 요약하고 지원 자격을 자동 분석, 마감일 기준 자동 정렬
- 향후 장학금, 인턴, 연구 프로그램으로 확장 가능

## 4. 요구사항

| ID | 우선순위 | 기능 | 완료 기준 |
|---|---|---|---|
| FR-01 | 필수 | 공모전 통합 검색 | 키워드, 분야, 마감일로 검색하면 여러 출처의 공고가 한 목록에 표시되고 마감일순으로 정렬할 수 있다. |
| FR-02 | 필수 | 공고 AI 요약 | 공고를 선택하면 AI가 지원 자격, 분야, 상금, 일정, 제출물을 요약해 보여 주고 원문 링크를 제공한다. |
| FR-03 | 필수 | AI 맞춤 추천 | 전공·관심 분야를 입력하면 적합한 공모전을 추천하고 추천 이유를 함께 제공한다. |
| FR-04 | 선택 | 관심 공모전·마감 관리 | 관심 공모전을 저장하고 마감일까지 남은 기간을 D-Day로 확인할 수 있다. |

## 5. 사용자 흐름

1. 첫 화면에 접속한다.
2. 전공, 학년, 관심 분야 또는 원하는 공모전 키워드를 입력한다.
3. 시스템이 조건에 맞는 공모전 정보를 검색한다.
4. AI가 각 공모전의 핵심 내용을 분석한다.
5. 사용자에게 적합한 공모전 목록을 보여 준다.
6. 사용자가 하나의 공모전을 선택한다.
7. AI가 지원 자격, 마감일, 상금, 제출서류 등 핵심 정보를 보여 준다.
8. 원하는 경우 관심 공모전으로 저장한다.

| 추천 결과 화면 | 추천 공모전과 추천 이유, 지원 자격, 접수 기간, D-Day, 상금/혜택, 제출 자료, 원문 공고 이동 |

## 7. 기술·처리 방침 (PRD 기준)

- 프론트엔드 Next.js + React, Tailwind CSS / 백엔드 Next.js API
- 데이터 저장: MySQL (공고 등)
- AI 기능: 공고 요약·추천
- 데이터 수집: 공개 API 및 허용된 범위의 웹 데이터 연동
- 처리 구조: 데이터 수집 → 정제 → 저장 → 검색·프로필 입력 → 관련 공고 검색 → AI 분석 → 추천·요약 제공
