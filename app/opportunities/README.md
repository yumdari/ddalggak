# 기회 정보 큐레이션

`/opportunities`에서 콘테스트코리아의 공개 공모전 목록과 국민대학교 공식 장학공지를 수집해 **공모전**과 **국민대학교 장학정보**로 나누어 보여 줍니다. 유형마다 세부 관심 분야를 선택해 전공과 함께 추천받을 수 있습니다. 카드에는 설명 대신 확인된 마감일을 표시하고, 날짜가 확인되지 않으면 원문 확인을 안내합니다. 공고를 열면 Gemini 요약을 요청하며, 결과마다 수집한 원문 텍스트에서 확인한 근거 문구를 표시합니다.

공모전은 AI·데이터, 개발·SW, 디자인·시각, 영상·콘텐츠, 기획·아이디어, 창업·비즈니스, 사회·환경, 인문·글쓰기, 과학·연구로 나눕니다. 장학정보는 생활비 지원, 등록금 지원, 성적·학업, 지역인재, 복지·가계, 전공특화, 국제·유학, 연구·대학원으로 나눕니다. 세부 분야는 공개 목록과 본문의 키워드로 추정하며 근거가 없으면 `세부 분야 미확인`으로 표시합니다.

`service.ts`가 이 서비스의 상위 진입점입니다. 공개 목록 수집(`_lib/feeds.ts`), 검색·추천 규칙(`_lib/catalog.ts`), Gemini 요약·추천(`_lib/ai.ts`)을 묶어 세 API 라우트에 제공합니다. 화면은 `_components/Workspace.tsx`에서 관리합니다.

## 환경변수

루트 `.env.local`에 아래 값을 설정합니다. 실제 키는 커밋하지 않습니다.

```dotenv
GEMINI_API_KEY=your-server-key
OPPORTUNITIES_GEMINI_MODEL=gemini-2.5-flash
```

키가 없어도 통합 목록·검색·기본 추천·원문 미리보기는 동작합니다. 화면은 Gemini 사용 여부를 표시합니다. 두 공개 페이지 수집에 별도 키는 필요하지 않습니다. 같은 `GEMINI_API_KEY`를 쓰는 학습 서비스와 모델 설정은 별개입니다.

## 데이터 범위

- [콘테스트코리아 대회·공모전 전체](https://www.contestkorea.com/sub/list.php?int_gbn=1) — 앞의 3개 목록 페이지에서 대학생·대학원생·누구나 대상 공고를 사용
- [국민대학교 장학공지](https://www.kookmin.ac.kr/user/kmuNews/notice/7/index.do) — 첫 목록 페이지의 공고와 각 공고 본문을 사용

서버는 공개 목록을 읽고 URL을 기준으로 중복을 제거하며 10분간 메모리에 보관합니다. 수집 실패 시 이전 캐시가 있으면 유지합니다. 콘테스트코리아의 접수 기간은 게시 일자의 연도와 함께 해석하며, 국민대학교 공고는 본문의 연도 포함 마감 문구 또는 제목의 명시적 월·일 기한만 사용합니다. 이미지에만 적힌 마감일은 추정하지 않습니다. 원문 링크를 제공하며 운영 전 재사용 조건을 확인해야 합니다.

현재 브랜치는 서비스 폴더 밖의 공통 의존성을 바꾸지 않도록 요청받아 MySQL 연동을 포함하지 않습니다. 따라서 서버 재시작 후 캐시는 다시 수집하며 관심 공고는 해당 브라우저에만 남습니다.
