# 딸각 PRD — ③ 강의자료 PDF 요약·퀴즈 (구현 기준)

> 원본: `(최종본) 7조딸깍_PRD (1).docx` (작성일 2026-10-03). 이 문서는 그중 **③ 강의자료 학습 지원** 부분만 추려 구현 기준으로 정리한 것이다. 기능을 추가하거나 바꾸면 이 문서를 같이 고친다. 원본과 다르면 제출 전에 팀과 맞춘다.

## 1. 서비스 맥락

- 팀: 7조 · 딸각
- 서비스명: AI 기반 학업지원 정보중계 플랫폼 서비스
- 구성: ① 기회 정보 큐레이션 ② 수강신청 플랜 B·C 도우미 ③ **강의자료 PDF 요약·퀴즈** ← 이 폴더
- 경로: `/study` · 폴더: `app/study/`
- 한 줄 소개: 교수님 강의자료(PDF)가 길고 방대해 시험 전에 핵심만 정리하고 복습하기 어려운 문제를, 요약과 퀴즈 생성으로 해결한다.

## 2. 문제와 사용자

- 문제: 강의자료 PDF가 길어 핵심 정리·복습이 어렵다.
- 대상: 대학생·대학원생
- 사용 상황: 시험 기간에 강의자료를 요약하고 퀴즈로 복습할 때
- 차별점: 강의자료 PDF를 요약하고, 요약 내용에서 바로 퀴즈를 생성한다.

## 3. 요구사항

| ID | 우선순위 | 기능 | 완료 기준 |
|---|---|---|---|
| FR-09 | 필수 | 강의자료 PDF 요약 | PDF를 업로드하면 AI가 목차별 핵심 개념과 용어를 요약해 보여 준다. |
| FR-10 | 필수 | 퀴즈 생성 | 요약 또는 선택한 범위를 기반으로 객관식 퀴즈를 만들고 정답, 해설, 힌트를 제공한다. |
| FR-11 | 선택 | 시험 범위 선택·오답 노트 | 원하는 쪽수나 단원만 골라 요약·퀴즈를 만들 수 있고 틀린 문제를 모아 다시 풀 수 있다. |

## 4. 사용자 흐름

1. 강의자료 PDF를 업로드한다.
2. 필요하면 요약할 쪽수나 단원 범위를 선택한다.
3. AI가 목차별 핵심 요약을 보여 준다.
4. 퀴즈 생성을 선택하고 문항 수를 정한다.
5. 퀴즈를 풀고 정답과 해설을 확인한다.
6. 틀린 문제는 오답 노트로 저장한다.

## 5. 화면 (학습 화면)

PDF 업로드 · 범위 선택 · 요약 결과 · 퀴즈 풀이 · 해설 · 오답 노트

## 6. 기술·처리 방침 (PRD 기준)

- 프론트엔드: Next.js + React, Tailwind CSS / 백엔드: Next.js API
- 데이터 저장: MySQL (퀴즈 결과 등)
- AI: OpenAI API (PDF 요약, 퀴즈 생성)
- PDF 처리: 업로드한 PDF에서 텍스트를 추출해 AI에 전달하고, **처리 후 원본 파일은 저장하지 않는 것을 기본**으로 한다.
- 배포·버전 관리: Vercel, GitHub
- 처리 구조: PDF 업로드 → 텍스트 추출 → 요약 → 퀴즈 생성 → 풀이 결과 저장

## 7. 이번에 만들지 않는 것 (이 서비스 관련)

- 대학 LMS 연동 (PDF는 사용자가 직접 업로드)
- 결제 시스템
- 네이티브 Android/iOS 앱
- 학교 포털 로그인 정보 수집·저장

## 8. 리스크·유의사항

| 항목 | 대응 |
|---|---|
| AI 오답 | 요약·퀴즈는 AI가 만든 것이므로 원문 확인을 안내한다. |
| 강의자료 저작권 | PDF 원본을 저장·공유하지 않고 본인 학습 용도로만 처리한다. |
| 개인정보 | 학교 계정 정보를 받지 않고, 입력한 정보는 최소한만 저장한다. |

## 9. 현재 구현 상태 (2026-10-03 기준)

### 구현됨

- FR-09: PDF 업로드(4MB 이하) → 개요 · 섹션별 요약. 요약의 각 항목에 **원문 쪽수 칩(p.N)**이 붙고, 누르면 왼쪽 원본 PDF가 그 쪽으로 이동한다. 핵심 용어는 굵게 표시한다.
- 핵심 개념·플래시카드는 해당 탭을 처음 열 때 만든다 (업로드 직후 대기 시간을 줄이기 위함)
- FR-10: 요약을 본 뒤 퀴즈 생성을 선택하고 **문항 수(3·5·10)를 정해** 객관식 퀴즈를 만든다. 문제마다 **힌트**, 정답, 해설, 결과 점수를 제공한다. 탭을 옮겨도 풀이 진행이 유지된다.
- 안내 문구: 업로드 화면과 결과 화면에 "AI가 만든 내용은 틀릴 수 있으니 원문 확인", "본인 학습 용도로만 사용", "PDF는 서버에 저장되지 않음"을 표시한다.
- 원본 PDF를 서버에 저장하지 않음 (요청 처리 후 폐기)
- **내 문서 목록**: 요약한 문서와 만들어 둔 개념·카드·퀴즈를 이 브라우저(IndexedDB)에 저장하고, 새로고침해도 목록에서 다시 열 수 있다. 삭제할 수 있다. 서버에는 저장하지 않는다.
- 좁은 화면에서는 "원본 보기" 버튼으로 PDF와 학습 화면을 전환한다.
- **추가 기능 (PRD 원문에 없음)**: 샘플 강의자료로 체험하기 버튼(파일 없이 바로 써 볼 수 있음), 플래시카드, AI 튜터(자료 기반 질의응답)

### PRD와 어긋나거나 빠진 것

| 항목 | PRD | 현재 | 조치 |
|---|---|---|---|
| FR-11 범위 선택 | 쪽수·단원 선택 | 없음 | 선택 항목. 시간 되면 쪽수 범위 선택 |
| FR-11 오답 노트 | 틀린 문제 모아 다시 풀기 | 없음 | 선택 항목. 시간 되면 브라우저 저장소로 구현 |
| 결과 저장 | MySQL 저장 | 서버 DB 없이 브라우저(IndexedDB)에 저장 | PRD 기술 구성 수정 필요 (MySQL → 브라우저 저장) |
| AI | OpenAI API | **Gemini**(기본, 과부하 시 대체 모델로 자동 전환) / Claude 선택 | PRD 부록·기술 구성 수정 필요 |
| PDF 처리 | 텍스트 추출 후 전달 | PDF를 AI에 그대로 전달 | PRD 문구 수정 필요 |

### PRD 수정이 필요한 곳 (제출 전 팀과 확인)

AI 자동 평가는 PRD와 배포된 서비스를 대조해 점수를 매기므로, 구현과 다른 기술 서술은 감점 요인이 될 수 있다.

- 8. 기술 구성의 "AI 기능: OpenAI API", "PDF 처리: 텍스트를 추출" → 실제 사용하는 AI와 방식으로 수정
- 부록의 "사용한 AI 도구 · 라이브러리" → Gemini API(`@google/genai`), 필요하면 Anthropic SDK로 수정
- 만들지 않기로 한 선택 기능(오답 노트, 범위 선택)은 PRD에서 "선택"에 그대로 두거나 범위 밖으로 옮기기
- 추가한 기능(샘플 체험, 플래시카드, AI 튜터, 내 문서 목록, 원문 쪽수 칩)을 PRD 요구사항에 넣을지 결정
- "데이터 저장: MySQL" → 브라우저 저장(IndexedDB)으로 수정하거나, 실제로 DB를 붙일지 결정
