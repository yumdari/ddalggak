# 딸각 PRD — ② 수강신청·학사 일정 도우미 (구현 기준)

> 원본: `(최종본) 7조딸깍_PRD.docx` (작성일 2026-10-03). 이 문서는 그중 **② 수강신청·학사 일정 도우미** 부분만 추려 구현 기준으로 정리한 것이다. 기능을 추가하거나 바꾸면 이 문서를 같이 고친다. 원본과 다르면 제출 전에 팀과 맞춘다.

## 1. 서비스 맥락

- 팀: 7조 · 딸각 / 서비스명: AI 기반 학업지원 정보중계 플랫폼 서비스
- 이 서비스: 수강신청에서 원하는 과목이 마감되면 대체 과목과 시간표를 즉석에서 다시 짜야 하는 혼란, 수강신청·정정·종합시험 같은 학사 일정을 놓치는 문제를 해결한다.
- 경로: `/course-plan` · 폴더: `app/course-plan/`

## 2. 문제와 사용자

- 원하는 과목이 마감되면 대체 과목과 시간표를 즉석에서 다시 짜야 해서 혼란스럽다.
- 수강신청, 정정 기간, 종합시험 신청 같은 학사 일정을 공지에서 놓치기 쉽다.
- 수강신청 실패나 일정 누락은 학점, 졸업 시기에 직접 영향을 주는 손해로 이어진다.
- 대상: 대학생·대학원생
- 사용 상황: 수강신청 기간에 희망 과목과 대체 과목을 계획할 때

## 3. 차별점

- 수강신청 실패 시 남은 학점과 시간표 충돌을 반영해 플랜 B, C로 즉시 전환 안내
- 향후 종합시험 정보로 확장 가능

## 4. 요구사항

| ID | 우선순위 | 기능 | 완료 기준 |
|---|---|---|---|
| FR-05 | 필수 | 학사 일정 알림 | 수강신청, 정정 기간, 종합시험 신청 일정을 D-7, D-1, 당일에 알려 주고 출처 공지 링크를 함께 표시한다. |
| FR-06 | 필수 | 수강신청 플랜 A·B·C 생성 | 희망 과목을 입력하면 시간 충돌과 학점 상한을 점검해 플랜 A와 대체 플랜 B, C를 자동으로 구성한다. |
| FR-07 | 필수 | 신청 실패 시 플랜 전환 안내 | 마감된 과목을 표시하면 남은 학점과 시간표를 반영해 다음 플랜을 즉시 제시하고 변경 이유를 설명한다. 실제 신청은 사용자가 직접 한다. |
| FR-08 | 선택 | 졸업 요건·종합시험 점검 | 성적표 정보를 입력하면 부족한 학점과 필수 과목, 종합시험 응시 조건을 정리해 준다. |

## 5. 사용자 흐름

1. 학기, 희망 과목, 학점 목표를 입력한다.
2. AI가 시간 충돌, 학점 상한, 선수과목 여부를 점검한다.
3. 플랜 A와 대체 플랜 B, C를 시간표로 보여 준다.
4. 수강신청 당일, 마감된 과목이 생기면 해당 과목을 표시한다.
5. AI가 남은 조건을 반영해 다음 플랜을 즉시 안내한다.
6. 사용자가 학교 수강신청 시스템에서 직접 신청한다.

## 6. 화면

| 화면 | 구성 요소 |
|---|---|
| 첫 화면 (일부) | 다가오는 학사 일정 |
| 수강신청 화면 | 희망 과목 입력, 플랜 A·B·C 시간표 비교, 과목 마감 표시 후 플랜 전환 버튼과 변경 이유 |

## 7. 기술·처리 방침 (PRD 기준)

- 프론트엔드 Next.js + React, Tailwind CSS / 백엔드 Next.js API
- 데이터 저장: MySQL (학사 일정, 사용자 프로필·플랜)
- AI 기능: 플랜 생성
- 학사 일정은 공지를 확인해 직접 입력한다.
- 처리 구조: 희망 과목·시간표 입력 → 충돌·학점 검사 → 플랜 A·B·C 생성 → 실패 과목 입력 → 다음 플랜 재계산

## 8. 이번에 만들지 않는 것

- 수강신청 자동 신청·매크로 기능 (플랜 안내까지만 제공하고 신청은 사용자가 직접 수행)
- 학교 포털 로그인 정보 수집 및 저장
- 대학 LMS 연동
- 결제 시스템, 네이티브 앱

## 9. 리스크·유의사항

| 항목 | 대응 |
|---|---|
| AI 오답·날짜 오류 | 학사 일정에는 출처 링크를 붙이고 '최종 확인은 원문 공지에서' 문구를 표시한다. |
| 개인정보 | 학교 계정 정보를 받지 않고, 입력한 성적·시간표는 최소한만 저장한다. |

## 10. 구현 상태

메인 앱 `/course-plan`에 수강 추천 MVP 통합 완료. 성향 입력, 결정론적 추천, 성공 과목 고정 및 실패 시 대체 추천을 제공한다. API는 `/course-plan/api/*`를 통해 기존 Python 백엔드에 연결한다. 가상 과목 데이터 기반이며 학사 일정 알림과 실제 졸업 요건 점검은 미구현이다.
